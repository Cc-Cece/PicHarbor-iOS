# 0.2.1 账号入口与无反馈操作排查

日期：2026-10-19。用户报告“添加 Google 账号”点击无反应，本轮检查账号及相关操作链路。

## 修复内容

- 添加账号改为当前导航栈内的登录页面，不再依赖账号列表的第二个 sheet；即使运行环境或账号操作尚未就绪，也能进入并看到原因。
- 初始化、连接、切换和清理忙碌状态显示原因。运行环境不可用时提供重新检查入口。
- `Engine.login` 和 `HarborModel.connect` 返回实际成功结果。操作因忙碌被拒绝时返回失败，保留已有账号；登录界面仅在此次连接成功后退出。
- Google 网页凭据在网页关闭完成后再交给连接流程，避免同时关闭两层界面。失败在当前连接页显示，不依赖底层页面的弹窗。
- 网页增加加载状态、超时、重新加载及导航/网页进程错误反馈。不承诺 Google 一定允许内嵌网页登录；拒绝时保留已有 gpmc 凭据导入入口。
- 未登录配置也持久化到本机独立配置，不混入任一账号；有账号时继续按账号保存。保存任务先固定账号和设置快照；范围确认只有保存成功才退出。
- 备份页提供账号连接入口；无账号时清理明确提示先登录。没有已完成备份时不再空跑云端核验。
- 手动备份空范围、已有任务和重新备份时原照片不可读，均有明确提示。成功入队显示“查看活动”；自动扫描不反复弹出这些提示。
- 已拒绝相册授权时显示真实状态和系统设置入口，不再提供重复请求但无法弹出系统授权的按钮。
- 脱敏诊断补充应用版本、构建号、初始化、运行环境和账号忙碌状态，不包含账号、凭据或页面地址。

## 回归范围

- 账号入口连续两次打开、进入 WebKit、取消并返回。
- 导入本机合成的无效凭据，确认留在页面并显示错误；不使用真实账号，不向 Google 提交此测试凭据。
- 运行环境不可用和忙碌时不能误报连接成功，忙碌操作不清空已有账号。
- 未登录时设置变更，终止并重启后仍保留。
- 既有 PhotoKit 图库/详情、默认画质、四个入口、核验设置和深色外观；新增未登录清理提示检查。
- Python 协议离线回归及设备 IPA 编译、包检查。

实际运行链接、检查结果和 IPA 校验信息见 `DEVELOPMENT-ACCEPTANCE.md`；只有检查完成后才记录通过。

## 仍未完成的验收及能力

苹果原始 Live Photo 资源配对的云端关联协议仍未实现；Motion Photo 官方客户端取回仍需真机验证。真实 Google 登录、账号切换、后台、相簿同步及本地删除流程仍须在用户设备验收。本轮账号页面测试不能替代这些云端和系统行为验收。完整清单沿用 `LIVE-PHOTO-VALIDATION.md` 和 `DEVELOPMENT-ACCEPTANCE.md`。
