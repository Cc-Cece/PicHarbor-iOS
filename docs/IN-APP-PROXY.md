# 应用内代理

入口：设置 → 应用内代理。默认关闭，只作用于 PicHarbor 的网络连接，无需创建系统 VPN。

## 添加配置

进入“配置与订阅”，选择其中一种方式：

- **添加订阅**：填写 HTTP 或 HTTPS 链接及名称，点击“下载并添加”。
- **扫码添加订阅**：使用相机扫描，或从相册选取二维码图片。识别结果先进入订阅添加页，查看或修改后再点击“下载并添加”。不会自动下载或保存识别出的链接。
- **导入 Clash 配置文件**：从“文件”选择完整的 Clash Meta YAML/JSON 文件。

扫码时才申请相机权限。拒绝权限或相机不可用时，仍可从相册选码或手动填写链接。从相册选码使用系统照片选择器，识别在本机完成，不上传图片。多个订阅二维码会先列出供选择。

当前只识别 HTTP/HTTPS 订阅二维码。VLESS、SS、TUIC 等单节点分享链接会明确提示，其他二维码不会打开网页或执行操作。

最多保存 20 份配置，每份最多 64 个节点。订阅手动更新；本地配置重新导入会新增一份配置。

## 连接与维护

1. 选择要使用的配置和首选节点，开启应用内代理。
2. 点击“测试当前连接”，查看首选节点访问 Google 测试地址的请求延时。
3. 需要备用节点时，勾选节点，并在“连接失败时”选择允许切换的方案。只有明确允许时才尝试直连。
4. 任务默认跟随全局，也可在任务详情设置独立连接策略，随任务保留。

配置详情可以编辑名称及订阅链接、手动更新、切换、移除或重新检查兼容性。更改链接后需更新订阅，才会改变节点内容。更新失败会保留上一份可用配置。

个别节点不能启动时，可用节点仍会导入；失败项及原因单独显示，并保留原始内容供重新检查。节点启动成功代表配置可以加载，能否访问 Google 仍需连接测试。流量、到期等与真实节点重复的订阅信息单独展示，不作为首选或备用节点。

更新或切换配置前需暂停活动备份。移除当前配置会关闭代理，不自动切换至其他配置。

## 后台与隐私

应用进入后台后，内置代理连接可能暂停；返回应用后可继续备份。它不具备系统 VPN 的常驻能力。

订阅地址、节点凭据和配置记录保存在本机 Keychain，不加入诊断报告或上传云端构建。二维码识别成功后，链接会在可编辑页面明文显示，便于检查。相机仅采集扫码画面，不录制音频或保存视频。

开源许可位于“设置 → 关于 PicHarbor → 开源组件”。
