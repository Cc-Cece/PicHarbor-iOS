# 0.2.13 · 界面、照片详情与活动归档

版本 0.2.13 / 构建 15，用户授权本轮完成后推送并云端编译。应用锁明确不在范围内。

- “语言”和“外观”合并为“界面”；上传画质、Live Photo 方式改为菜单选择器。现有偏好保留。
- 队列顶部提示 10 秒后消失；备份页“释放 iPhone 空间”提前到“当前设置”前。保留 0.2.12 真实直达链接及折叠备用方式，并修正折叠按钮继承重复 accessibility 标识的问题。
- 照片主详情增加文件名，显示实际资源大小、类型和日期；分辨率放入右上角“详情”。Live Photo 合计当前版本照片及配对视频大小，面板分别列出。大小按公开 PhotoKit 流式读取，不保留整段媒体数据，不使用私有 KVC；iCloud 不可用时显示提示，允许用户明确请求下载。
- 详情面板显示可读取的格式、分辨率、时间、时长、设备、镜头、曝光及位置，不提供编辑。拍摄参数仅在本机可读取时展示，地图使用照片已有位置。
- 右上角系统分享菜单按文件导出照片/视频，保持资源编码及元数据；Live Photo 分享照片和对应视频两项，预先说明接收应用决定是否按动态照片接收。没有将静态预览冒充动态分享；AirDrop、消息及其他接收端的动态兼容性需真机验收。分享可取消，暂存文件在分享结束或失败后移除。
- 任务全部资源通过查重复用且符合当前确认策略，显示灰色“已存在，跳过”；混合复用与新上传显示“已备份”并说明部分复用。Live Photo 仍需同一云端项目配对。旧记录不推断复用来源，不追溯改名。
- 原“按当前设置重新备份”移入高级信息，改为“使用当前设置创建任务”：跳过本机旧任务抑制，但不启用强制上传；照常进行云端查重和配对确认，保留原任务。
- 活动记录支持单条、当前筛选批次及多选归档，归档页可筛选、查看详情并取消归档。归档只存储日期，备份状态、发现去重、云端映射不变；图库及备份累计数量仍包含归档记录。
- 设置 → 活动记录：自动归档默认开启，14 天，接受 1–90 的整数；在启动、进入活动页、设置变化及运行期间定期处理，仅按完成时间归档已完成任务。取消归档后重新等待设定天数。此偏好属于本机，适用于本机各账号，任务仍按账号隔离。
- 大批量归档使用带版本号的 SQLite 事务，保留历史记录；旧版可选字段迁移兼容，未完成、失败和暂停记录不会自动归档。

本机 58 项 Python 回归及多语言覆盖检查通过；新增原生测试覆盖归档期限、输入校验、持久化版本、旧记录兼容及复用判定。云端编译、模拟器结果及 IPA 指纹将在完成后补充。
