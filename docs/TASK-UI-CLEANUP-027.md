# 0.2.7 任务界面、标准检查与释放空间

## 任务详情

主页面显示本机缩略图、任务状态、备份方式摘要、流程、可操作提示及操作。流程为准备照片、上传资源、确认保存、完成；只有开启严格 Live Photo 核验时才增加严格核验步骤。暂停和错误停留在当前阶段。

资源清单、配对路径、系统错误、错误码、查询次数、时间和耗时移入“高级信息”原生中/大尺寸弹窗。可导出脱敏诊断，包含随机任务引用、状态、原因、计数；不包含账号、文件名、内容哈希、云端标识、私有路径、凭据或签名地址。

## 标准与严格备份检查

- 新增高级开关“严格核验 Live Photo 动态就绪”，默认关闭。旧设置缺少字段时也采用标准策略，已有已完成记录保持原样。
- 标准模式仍要求提交后内容确认。原始 Live Photo 必须逐版本确认照片哈希及动态视频哈希属于同一项目；Motion Photo 必须确认完整封装内容。仅传输成功不足以完成。
- 严格模式继续等待云端处理状态和动态标记，原始配对通过时显示蓝色，最终通过才绿色。
- 核验级别单独保存，不因标准任务绿色而声称严格动态验证通过。此开关不改变画质/封装、不改变内容去重键、不自动重新上传。
- 新设置影响新任务。可显式应用到已有待确认任务，或在任务详情按当前策略继续，保留账号、资源、内容策略、来源及批次。0.2.6 缺少该字段的旧待确认任务在新版本按默认标准策略继续。
- Live Photo 清理仍关闭；完整成员取回能力尚未完成验证，不以标准完成或配对标识替代原件可取回证据。

## 活动与批次

- 来源：全部来源、手动、自动；状态：全部、未完成、已完成。未完成包括等待、暂停、失败和蓝色核验任务，已取消仅显示于全部。
- 批次在筛选前建立。多任务批次显示卡片，点击进入当前筛选下的列表；只有一个任务时直接平铺。同一批原有多项、筛选后剩一项时仍保留卡片。
- 未记录批次的旧任务不凭空合并，未知来源可通过全部来源查看。早期验证记录独立入口，不取得清理资格。
- 批次与主列表的暂停、继续、移除仅针对当前结果；移除任务保留本机和云端照片。

## 释放空间

- 页面只汇总当前账号仍可访问的已完成本地资产，同一资产选择最新的已完成记录，逐项重新验证完整覆盖；不将不同账号、不同资源版本的证明混合。
- 开始检查固定账号、策略与候选集；无需全局暂停备份。同一照片有正在处理或排队的任务时跳过，其余候选在检查期间禁止新备份调度；其他照片继续推进。
- 导出/哈希共用有界准备门；PhotoKit 导出前后检查版本，云端状态、内容及原件访问继续按清理策略执行。其他上传使云端快照过期时可在核验请求内刷新，不使用过期证据。
- 显示进度，可停止、按结果筛选并逐项重试。结果区分可清理、暂不能、失败、已处理。默认不选中，用户显式全选或逐项选择；新增结果不自动扩大选择，失效结果从选择中移除。
- 删除前复用五分钟内且账号、版本、策略和源清单均匹配的证据；过期或变化时重新核验。单项失败/过期不授权删除该项，也不阻断其余所选有效项。系统删除只收到本轮再次通过的用户所选本地资产。
- 账号切换在检查/删除期间阻止；网络策略变更取消扫描并应用到任务。清理策略变更使证据失效。用户取消系统删除时保留记录与重试入口；不会执行云端删除。
- iCloud 删除同步提示与 PhotoKit 系统授权保留。当前清理仍只开放普通照片与视频。

## 回归与真机验收

自动回归覆盖默认策略迁移、完整配对前置条件、检查策略不造成重传、双维筛选/稳定批次、清理按账号去重、选择不自动扩大、脱敏诊断、流程截图及严格设置持久化。

真机验证：多选创建批次、双维筛选、单项平铺、批次内操作、任务流程及高级弹窗；标准 Live 完成与严格蓝色等待；普通备份进行时检查另一张已完成照片；停止/重试、默认不勾选、取消勾选不被新增结果覆盖；专用普通测试照片的选择与系统删除取消/成功。Live Photo 不应进入可清理列表。

编译、回归和包检查结果完成后记入交付台账。
