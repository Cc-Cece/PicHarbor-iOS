# 相片备份状态筛选 · 0.2.29（build 31）

相片页在相簿标题下增加“全部／已备份／未备份”三段筛选，初始显示全部。与相簿和媒体类型筛选取交集，项目数和“选择当前范围全部”按筛选结果计算。切换条件保留已有选择及已选数量；全选当前范围将可见项目加入选择，不清除其他范围已选项。

## 判断规则

- 已备份：当前账号、同一 PhotoKit 资产 ID 及当前版本标记存在已完成记录，包括“已存在，跳过”和已归档记录。
- 未备份：没有上述完成记录。排队、传输、暂停、失败及蓝色对勾阶段本身不算完成。
- 同一版本后来新增未完成任务，不抹掉此前完成记录。编辑产生新版本时，旧版本完成记录不直接授予新版本已备份状态。
- 沿用任务完成标准；已按选定策略完成的任务，不因可选的后续动态处理检查而归入未备份。
- 切换账号后按新账号记录判断。没有账号时不显示已备份项目。

页面提示：“备份状态以当前账号的记录为准。”不会逐张请求 Google 云端；官方客户端独立上传或后来云端删除的变化可能尚未体现在应用记录中。

## 性能与验证

完成记录维护为账号隔离的资产／版本集合，不对每张照片扫描全部任务。只在新增完成证据、图库、相簿、账号或筛选条件变化时刷新相应缓存；普通上传进度更新不重复计算筛选。“全部”范围不因新增完成记录重新加载整个网格。
