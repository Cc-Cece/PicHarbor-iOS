# 0.2.9 语言、日期、文件名与恢复默认

## 行为

- 设置新增语言页：跟随系统、简体中文、English、粵語（香港）。语言保存在设备偏好，不随账号切换及恢复业务默认值改变。页面、流程及提示订阅语言变化，即时更新，保持导航位置；系统优先语言变化在界面重新求值时解析。
- 使用原生 `.lproj/Localizable.strings`、本地化权限说明及正式 bundle 语言声明。默认开发语言为 `zh-Hans`，包含 English 及香港本地化；香港资源使用香港用词与粤语提示，具体审校覆盖在 `Localization/hong-kong-overrides.tsv`，不是仅作简繁转换。应用自身共 480 条文案，英文表完整覆盖并验证插值参数。Google 网页和 iOS 自有授权界面由各自提供方决定语言。
- 切换语言时静态的既有运行提示和清理结果可重新解析，文件名、账号、相簿名称等用户内容不翻译。错误码、协议标识及数据库枚举不翻译。
- 活动、批次、照片详情及高级信息的日期按应用语言格式化，时区沿用设备；时间模板使用设备的 12/24 小时偏好。任务详情顶部不显示日期，完整创建时间保留在高级信息。
- 任务详情文件名最多两行、中间截断，保留扩展名；点击展开完整名称并可选择复制，长按可直接复制。活动中的文件名仍进入任务，不因详情专属点击处理而拦截导航。

## 默认值与升级

新安装/未保存的账号设置及恢复默认时，Live Photo 默认采用原始照片配对（联合提交）。已有保存的选择和历史任务完全保留；旧库没有记录是否“主动选择”，因此不猜测并覆盖既有值。所有内容设置仍仅影响新任务，不自动重传图库。

| 设置 | 默认值 |
| --- | --- |
| 上传画质 | 不计配额原画质 |
| Live Photo | 原始照片配对 |
| 编辑版本 | 原始与编辑后均保留，相同内容去重 |
| 范围 | 全部可访问内容，首次须确认 |
| 自动备份 | 初始关闭；首次确认范围页默认勾选开启 |
| 网络 | 仅 Wi-Fi |
| 相簿同步 | 关闭 |
| 等待云端完成动态处理 | 关闭 |
| 最新云端状态 / 原件访问 | 均开启 |
| 允许清理未完整验证的 Live Photo | 关闭 |
| 外观 / 语言 | 跟随系统 |

“恢复备份与清理默认设置”需确认，重置当前账号上述业务设置；保留当前语言、外观、账号、任务、历史和照片。范围回到未确认状态，自动备份关闭，清理结果失效。已有任务的内容快照不改写；仅网络依既有规则应用到当前账号未完成任务，手动暂停保持暂停。不会删除或重新上传任何照片。核验、删除及账号切换过程中不能恢复，设置存储失败不宣称恢复成功。

## 维护与验证

源文案在 `Localization/english.tsv`，香港审校在 `Localization/hong-kong-overrides.tsv`；`tools/build_localizations.py` 生成已提交的原生资源。仅重新生成香港基础字形时使用 `opencc-python-reimplemented==0.1.7`，该工具不内嵌、不新增 iOS 运行依赖；最终文案以原生资源和香港覆盖表为准。

`tools/localize_swift.py --check` 检查漏接的源文字，离线资源回归核对所有语言 key、参数、英文未翻译字及权限文案。原生回归覆盖语言解析、实际打包译文、中文日期、旧配置升级、恢复范围和清理默认值、已有任务内容不变。界面回归覆盖三种语言即时切换和重启保持、默认恢复取消/确认、文件名展开，以及原有流程。

本机及云端 56 项离线检查、46 项原生单元及 12 项界面测试全部通过（共 114 项），构建与包检查通过。运行与 IPA 信息见交付台账；0.2.10 在此基础上调整清理列表和风险说明。不将编译或模拟器结果视为真机结果。
