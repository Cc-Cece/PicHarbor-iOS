## 设计约定

- iOS 作为独立产品设计，使用适合 iPhone 的导航、列表、照片浏览和面板结构。
- 不继承安卓 UI 代码或视觉样式。安卓仅用于核对功能、业务规则和必要的信息组织。
- 网页只作为审核参考，不接入真实服务。正式应用使用 SwiftUI/原生组件实现认可的界面与交互。
- UI 与完整实施计划均已确认，用户补充要求见 `REQUIREMENTS.md`，当前进展与待验收项见 `IMPLEMENTATION.md`。

## 已确认的补充要求

- 原生应用将“gpmc 原画质”改名为“不计配额原画质”，设为默认；网页原型不作为实际默认设置的来源。
- 正式应用通过 PhotoKit 直接展示可访问的照片、视频与相簿，区分完整和有限授权，并识别新增、修改内容；后台执行另行设计。
- 在备份偏好中增加独立的“Live Photo 备份方式”：Motion Photo 为默认，苹果原始资源配对方式也列入支持目标。
- 第二种方式需实现云端正确关联与完整恢复，不能把分别上传两个文件当作完整支持。
- `MotionPhoto2` 为只读技术参考，不作为 UI 模板；来源与移植边界见 `MOTIONPHOTO2-REFERENCE.md`。

## 审核范围

21 个主要页面，36 种场景；照片、备份、活动、设置四个主入口，另有首次使用、照片详情、上传模式、范围、任务详情、核验与清理、账号、权限、网络、外观和诊断等页面。

支持多选照片、备份确认、暂停继续、模拟重试、账号切换、清理双重确认，以及浅色/深色预览。全部账号、照片、文件名、数字与操作结果为模拟内容。

桌面提供目录、交互预览、页面总览和状态切换；手机端可使用顶部“原型导航”访问其他页面。
