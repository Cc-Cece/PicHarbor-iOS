# iOS UI 审核原型

2026-10-19，第一版已发布，等待用户审核确认。

审核地址：https://picharbor-ios-design.yrkvjbcvbp.chatgpt.site

## 设计约定

- iOS 作为独立产品设计，使用适合 iPhone 的导航、列表、照片浏览和面板结构。
- 不继承安卓 UI 代码或视觉样式。安卓仅用于核对功能、业务规则和必要的信息组织。
- 当前只制作网页原型，不接入真实服务，不修改已通过 A/B 验收的原生业务实现。
- UI 未确认前，不进入下一阶段原生界面实现与 C 阶段功能开发。

## 审核范围

21 个主要页面，36 种场景；照片、备份、活动、设置四个主入口，另有首次使用、照片详情、上传模式、范围、任务详情、核验与清理、账号、权限、网络、外观和诊断等页面。

支持多选照片、备份确认、暂停继续、模拟重试、账号切换、清理双重确认，以及浅色/深色预览。全部账号、照片、文件名、数字与操作结果为模拟内容。

桌面提供目录、交互预览、页面总览和状态切换；手机端可使用顶部“原型导航”访问其他页面。

## 检查与来源

- 393 × 852 手机视口及桌面缩放检查。
- 浅深色共 72 个页面/场景组合无横向溢出或空白页面，控制台无错误。
- 主要交互流程与选择数量反馈已检查。
- 原型源代码位于本项目 `ui-prototype/`，由独立 Sites 源仓库管理；发布源码提交为 `05c11562e6ca0b2a09b7fe79d84ea0d956c58923`。
- 示例照片来源和本地预览方法见该目录的 README 与资源声明。

网页不是最终 SwiftUI 的渲染结果。系统授权、照片选择器与原生转场需在原生实现时核对。
